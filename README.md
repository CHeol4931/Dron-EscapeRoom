드론 방탈출 게임 설명서
목표

맵에 숨겨진 상호작용 7개를 모두 작동시킨 뒤, 출구에 도달해 탈출하세요.

조작법
키	동작
W A S D	플레이어 이동
마우스	시점 회전
E	바라보는 장치 작동 (3m 이내)
Q	드론 컨트롤러 열기/닫기
R	지상 드론 조종 (컨트롤러가 열린 상태에서)
T	비행 드론 조종 (컨트롤러가 열린 상태에서)

같은 키(R 또는 T)를 한 번 더 누르면 컨트롤러 메뉴로 돌아오고, Q를 누르면 컨트롤러가 닫히며 플레이어로 돌아옵니다.

드론 조종

지상 드론 (R)

W/S: 전진·후진
A/D: 제자리 회전
마우스 왼쪽 클릭: 발사

비행 드론 (T)

WASD: 이동
Space: 상승
Left Ctrl: 하강
마우스 좌우: 회전
조종하지 않을 때는 제자리에서 호버링
진행 순서
맵을 돌아다니며 장치 7개를 찾아 E로 작동시킵니다. 화면에 Interactions: n/7이 표시돼요.
7개를 모두 완료하면 All done! Reach the exit.가 나옵니다.
출구에 닿으면 ESCAPED! 탈출 성공이에요.
7개를 채우기 전에 출구에 닿으면 Locked.가 뜨고 탈출할 수 없습니다.
팁
드론을 조종하는 동안에는 플레이어가 움직이지 않고 E도 먹히지 않으니, 장치는 컨트롤러를 닫고(Q) 작동시키세요.
비행 드론으로 높은 곳이나 좁은 곳을 먼저 정찰하고, 지상 드론으로 적을 유인하면 편해요.
